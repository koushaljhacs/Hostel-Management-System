What to Do When Server is Down
------------------------------

Step 1: Check the Time
- Look at current time on your computer
- If between 11:45 PM and 9:00 AM - Normal
- If between 9:00 AM and 11:45 PM - Problem

Step 2: Continue Local Development
- Server down is NOT an emergency
- Continue working on localhost:3000
- Test everything locally first
- Server is for final check only

Step 3: Contact Team Lead if Needed
- If server down during open hours
- Send message to Team Lead
- Include time and what you were doing
- Wait for response, don't panic

Step 4: Be Patient
- Server issues are normal with free service
- Local development should be your focus
- Team Lead will fix when possible
- Never stop working because server is down
