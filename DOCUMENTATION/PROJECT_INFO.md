Hostel Management System - Project Information
==============================================

What This Project Does
----------------------
This is a software system for college hostels. It helps manage:
- Student hostel bookings
- Room allocations
- Payments and fees
- Staff management
- Food services

Who Uses This System
--------------------
1. Students - Book hostels and pay fees
2. Wardens - Manage hostel operations
3. Administrators - Oversee entire system
4. Staff - Handle maintenance and services
5. Parents - Check student information

What is Working Now
-------------------
- Student login system
- Basic dashboard for students
- Database connection
- Web interface

What We Are Building Next
-------------------------
- Student registration system
- Hostel booking feature
- Payment processing
- Room allocation system

Important Notes
---------------
- This is a development project
- Not ready for real-world use yet
- For demonstration purposes only
- Data is sample data for testing

System Requirements
-------------------
- Needs computer with Node.js and PostgreSQL
- Internet connection for some features
- Modern web browser like Chrome or Firefox
